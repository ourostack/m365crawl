# m365crawl v0.7.0

`v0.7.0` brings new Outlook's cached mail to Windows through the same archive and commands used on macOS. It also strengthens Windows browser shutdown and includes internal groundwork for future Microsoft 365 integrations.

## Windows Outlook mail

`m365crawl sync` now reads new Outlook's local OWA offline cache: folders, messages, cached bodies, ordered To/Cc/Bcc recipients, attachment metadata, read and flag states, and conversation identities. The default source is `%LOCALAPPDATA%\Microsoft\Olk\EBWebView`; `--outlook-root` selects an explicit supported cache and `--outlook-root none` disables Outlook.

Use `mail`, `search --source mail`, `overview`, `status` and `doctor` to read and inspect the archived mail. A cache is not a complete mailbox export: bodies or messages that Outlook has not cached are unavailable. Attachment content is not downloaded.

The archive upgrades to schema 8 through the normal command path. Existing Mac mail identifiers and default behavior are preserved. Native recipient roles are nullable for legacy mail, and conversation grouping remains account-scoped. Do not manually alter or vacuum the archive.

Windows Outlook calendar is not included in this release. Teams calendar remains supported, and existing Mac Outlook calendar behavior is preserved. OWA calendar is the next Windows parity outcome.

## Windows browser shutdown

Browser shutdown now waits for bounded, exact-owned process generations to signal exit before reporting completion. Disappearing profile or job membership alone is not proof of exit; failures remain explicit without extending the teardown allowance.

## Other changes

This release includes internal readers and capture backends for Office document metadata and OOXML text, OneDrive metadata, OneNote indexed text, Outlook people and attendees, cached Loop, Teams bot citations, SharePoint content and Engage. These are backend groundwork, not new public sync/search commands or complete cloud-source support. Planner/To Do assigned tasks and private Copilot history remain outside the current expansion.

The README and installed guide clarify shipped versus planned support. Contributors now use changelog fragments, and coverage failures report exact uncovered statement blocks. See `CHANGELOG.md` for the complete assembled changes.

## Install

### macOS

```sh
brew install ourostack/tap/m365crawl
```

For an existing installation, use `brew upgrade m365crawl`. Alternatively, download `m365crawl_0.7.0_darwin_arm64.tar.gz` or `m365crawl_0.7.0_darwin_amd64.tar.gz`. Darwin binaries are signed and notarized. Reading Teams and Outlook requires Full Disk Access for the terminal or agent host.

### Windows

Download `m365crawl_0.7.0_windows_amd64.zip` or `m365crawl_0.7.0_windows_arm64.zip`, unzip it and run `m365crawl.exe`. Windows assets are intentionally unsigned; verify the archive against the release's `checksums.txt` before running it. Replace the existing executable to upgrade, then use normal m365crawl commands to upgrade the archive.

The sources remain read-only. Windows archive privacy requires an owner-private containing directory and private existing database/sidecar files; unsafe paths fail before opening SQLite for writing. No authentication or attachment download is added by Windows cached-mail support.
