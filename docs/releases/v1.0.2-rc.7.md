# m365crawl v1.0.2-rc.7

**Controlled publish-failure and recovery rehearsal.** This candidate exercises failure reporting and a separate main-branch dispatch that must resume publication from the existing release assets, without rebuilding or signing again.

After normal signing, native artifact verification and published-body checks, a bounded rehearsal will deliberately prevent the tap push. The initial rehearsal includes an observation window before that push; stable publication and publish-only recovery do not wait. Recovery must complete through the normal publish-only path. These are required observations, not claims that the failure and recovery have already occurred.

This candidate includes the scoped 1.0.2 publishing/Go 1.27.3 patch, joined file-event shutdown and compatible Windows mail reader-release repair. Public commands, acquisition defaults, archive schema 19 and native source availability are unchanged. Windows OWA calendar and several populated content mailboxes per profile are not included; local-cache coverage is not server completeness.

This is a publisher rehearsal, not the default installation. The latest stable release and stable m365crawl cask must remain unchanged.

## Install

For ordinary macOS use, keep the latest stable Homebrew installation.

On Windows, download m365crawl_1.0.2-rc.7_windows_amd64.zip or m365crawl_1.0.2-rc.7_windows_arm64.zip, verify checksums.txt, unzip into a user-owned directory and run m365crawl.exe. **Windows binaries are intentionally unsigned.**
