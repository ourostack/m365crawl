# m365crawl v1.0.0

**A stable contract for the archive and commands already supported.**

This release hardens the documented compatibility promise, not the runtime:
it adds no source ingestion, acquisition behavior, archive migration or new
text-clipping semantics.

## The 1.x promise

Supported CLI commands, flags/defaults, structured field names/types and
null/omission semantics, streams, errors/exits, published SQL columns and
source/account/native-scoped identity rules are stable within 1.x.
Incompatible public changes require a new major release; a changelog entry
alone does not permit them. Compatible fields and open-vocabulary codes may
be added, so consumers must tolerate unknown additions.

The archive remains schema 19 with derivation baseline 2. Compatibility is
directional: newer supported builds migrate older supported archives at the
documented writable-open/explicit-sync boundary. Older binaries refuse higher
schemas on reads and writes; an old 1.0 binary is not promised to open every
future 1.x archive. Internal columns are not a stable SQL interface.

## Keep the source boundaries

The archive knows what supported sources retained, not complete service history.
Registered-source reads may refresh eligible registered inputs under their
documented rules; truly archive-only reads retain their no-acquisition boundary.
Observation IDs are archive-scoped, not universal person or cross-app identities.
Cached draft bodies and revision guards do not prove current editor/server-unsent
state, draft lifecycle or all-drafts completeness.

Existing source/platform limits remain: Windows binary availability does not
qualify every native Windows source, and Windows OWA calendar ingestion is not
included. Private Copilot history and assigned Planner/Microsoft To Do task
ingestion remain deferred and not included. Bot claims and recap actions are
not substitutes for those sources.

## Install

On macOS, use `brew install ourostack/tap/m365crawl` or
`brew upgrade m365crawl`, or verify the matching Darwin tarball against
`checksums.txt`. Darwin binaries are Developer ID signed and notarized by
the normal release pipeline.

On Windows, download `m365crawl_1.0.0_windows_amd64.zip` or
`m365crawl_1.0.0_windows_arm64.zip`, verify it against `checksums.txt`,
unzip the Windows ZIP into a user-owned directory and run `m365crawl.exe`.
**Windows binaries are intentionally unsigned.**
