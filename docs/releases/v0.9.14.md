# m365crawl v0.9.14

**Find cached teams even when none of their child channels is cached.**

## Space-only teams

`teams` now includes an archived conversation of kind `Space` without requiring
a separate cached child channel. `--team` accepts that root's exact display name
(case-insensitive for ASCII letters) or ID, and team-filtered message and search
reads include its own root messages.

The existing same-account child-reference inference remains available for other
cached team shapes. Account filters and ambiguous-name errors remain unchanged;
a self-referencing ordinary chat alone is not treated as a team.

`channel_count: 0` means no distinct child conversations are archived, not that
the service has no channels. This correction reads already archived data; it
does not fetch missing channels or change sync freshness.

There is no archive schema, mapper, acquisition or identity-policy change.

## Install and platform scope

On macOS, use `brew install ourostack/tap/m365crawl` or
`brew upgrade m365crawl`, or verify the matching Darwin tarball against
`checksums.txt`. Darwin binaries are Developer ID signed and notarized.

On Windows, download the matching amd64 or arm64 ZIP, verify its checksum,
unzip it and run `m365crawl.exe` from your user-owned installation.
**Windows binaries are intentionally unsigned.**

This portable archive-query correction adds no native Windows service
acquisition qualification.
