# m365crawl v0.9.5

**Your agent can now search and read the Loop text already sitting in your archive.** Microsoft 365 apps keep cached Loop snapshots on disk, and m365crawl already archives them. This release turns them into searchable channel text. Nothing is fetched and Loop is never opened.

## Cached Loop channels

```sh
m365crawl loop sync
m365crawl loop sources
m365crawl loop list
m365crawl loop search "launch plan"
m365crawl loop show loop-channel:12
m365crawl search "launch plan" --source loop
```

- Each row is one channel of one immutable snapshot version, with a stable `loop-channel:ID`, its native sequence and pending-operation count.
- It is **partial text, not a full or current Loop page**. Every row says `text_state: partial_snapshot`, and tells you whether the archived record still matches the snapshot it came from.
- `search` includes Loop channels with `--source loop`, and with `--source all` when no date, account, author, chat-only, mail-only or profile filter applies. Loop hits have no native date, so they follow dated hits. A compact `loop_coverage` says what was searched, even with zero hits.
- A source keeps its `source_id` from the first attempt. If one fails, `loop sources` shows why and `loop sync --source-id N` retries it. A failed refresh keeps the last good snapshot.
- `loop sync` registers at most 128 new records per run and says `discovery_remaining` when more are left, so a large backlog never blocks.
- The bare `m365crawl` overview has a `loop` row and a "Start here" line.

## Upgrading

The archive moves to schema 13. The change only adds Loop tables; existing rows are not rewritten. Run `m365crawl doctor` after upgrading, then `m365crawl loop sync` to project the Loop records your archive already holds.

See the [changelog](https://github.com/ourostack/m365crawl/blob/v0.9.5/CHANGELOG.md) and [SPEC](https://github.com/ourostack/m365crawl/blob/v0.9.5/SPEC.md) for the exact contract.

## Install and upgrade

On macOS, use `brew install ourostack/tap/m365crawl` or `brew upgrade m365crawl`. Alternatively, download the matching Darwin tarball and verify it against `checksums.txt`. Darwin binaries are Developer ID signed and notarized.

On Windows, download the matching amd64 or arm64 zip, verify its checksum, unzip it and replace `m365crawl.exe` in your user-owned installation. **Windows binaries are intentionally unsigned.**
