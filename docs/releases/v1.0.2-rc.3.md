# m365crawl v1.0.2-rc.3

**Continuation publication rehearsal.** This candidate is submitted with v1.0.2-rc.2. The normal publisher must finish the lower pending version and start a separate Release run for this version without a manual tag or asset upload.

This candidate includes the scoped 1.0.2 publishing/Go 1.27.3 patch, joined file-event shutdown and the compatible Windows mail reader-release repair. A mail snapshot is retained and reported when reader release cannot be proved, while the original failure or cancellation is preserved.

Public commands, acquisition defaults, archive schema 19 and native source availability are unchanged. Local-cache coverage is not server completeness; Windows OWA calendar and several populated content mailboxes per profile are not included.

This is a publisher rehearsal, not the default installation. The latest stable release and stable m365crawl cask must remain unchanged. Signing, notarization, downloaded macOS/Windows verification, published-body checks and the rehearsal tap remain required; this file does not claim they have finished.

## Install

For ordinary macOS use, keep the latest stable Homebrew installation.

On Windows, download m365crawl_1.0.2-rc.3_windows_amd64.zip or m365crawl_1.0.2-rc.3_windows_arm64.zip, verify checksums.txt, unzip into a user-owned directory and run m365crawl.exe. **Windows binaries are intentionally unsigned.**
