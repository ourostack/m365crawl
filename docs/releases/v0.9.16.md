# m365crawl v0.9.16

**Understand native attendee scope before following up.**

Native attendee `list` and `show` now explain when an explicit account selector
can exclude source-local, unlinked evidence. The `sources` command distinguishes
archive-wide diagnostics from account-qualified read results. Follow-up guidance
offers deliberate inspection of the same archive and observation without the
account filter; it does not guess an owner or silently widen a read.

Owner qualification, selection, audit history, error codes and acquisition
behavior are unchanged. Native observations still do not establish a current
attendee roster or resolved identity. There is no archive schema change.

Root help and the embedded guide now explicitly state that private Copilot
history and assigned Planner/Microsoft To Do task ingestion are not included.
Cached bot claims and recap actions are not substitutes for those deferred
sources.

## Install and platform scope

On macOS, use `brew install ourostack/tap/m365crawl` or
`brew upgrade m365crawl`, or verify the matching Darwin tarball against
`checksums.txt`. Darwin binaries are Developer ID signed and notarized.

On Windows, download the matching amd64 or arm64 ZIP, verify its checksum,
unzip it and run `m365crawl.exe` from your user-owned installation.
**Windows binaries are intentionally unsigned.**
