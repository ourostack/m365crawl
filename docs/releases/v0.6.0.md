# m365crawl v0.6.0

`v0.6.0` adds meeting transcripts. m365crawl lists every recorded meeting the Teams cache knows about, fetches each transcript once from SharePoint through its own invisible browser, and from then on reads it offline: show it, search it alongside chats and mail, and see it in `calendar event`. Agents can also hand m365crawl any Teams link the user pastes.

## Added

- **Meeting transcripts.** `transcripts` lists recorded meetings and the transcript parts each one has; `transcripts show <meeting>` prints a meeting's whole transcript, every part in time order with each seam marked. A meeting can be named by its call, its Teams chat, its calendar event or a Teams link. Both commands read the archive offline.
- **Fetching transcripts, local first.** `transcripts fetch <meeting>` (or `--since DATE`) downloads the parts not yet stored, through an invisible Edge (or Chrome) that m365crawl starts with its own browser profile, and stores them; parts already stored are not fetched again. m365crawl never sees a password or token, and it reaches only SharePoint hosts.
- **Sign-in, usually silent.** On a Mac where the organization's single sign-on already covers the browser, `transcripts fetch` signs in on its own and no window appears. Where it cannot, `transcripts signin` opens m365crawl's browser profile in a visible window once so the user can sign in to Microsoft 365. An agent must ask the user first: without a terminal, `signin` refuses unless given `--user-agreed`, and it prints each step so the agent can relay it. If that window asks to enroll or register the device, the organization signs in only from managed devices; the agent tells the user and does not retry.
- **Transcripts everywhere.** `search` includes fetched transcripts (one result per part, with how many lines matched; `--source transcripts` searches only them, and `--from` matches the speaker), `calendar event` lists a meeting's recorded calls and what is fetched, `status` counts them, and `doctor` checks for a browser and that the browser profile is private.
- **Any Teams link.** `thread`, `transcripts` and every `--conversation` flag accept a pasted Teams link: channel, chat, message or meeting links, from teams.microsoft.com, teams.cloud.microsoft or teams.live.com. A link to a conversation Teams has not cached says to open it once in Teams and sync.
- **Calendar ids and an unread total.** Calendar items carry `id` (the same value as `event_id`), and `mail unread` has `unread_total`.

## Changed

- **Network use.** `transcripts fetch` and `transcripts signin` are the only commands that use the network, and only through the browser m365crawl starts; every other command stays offline.
- **Archive format 7.** The archive gains transcript tables. A v0.5.0 archive is upgraded the first time this version syncs it.

## Fixed

- **Mail folders are no longer labelled junk.** Outlook's general folder type was read as "Junk or To Me", so user folders and several system folders showed as `junk`. They are now `other`, and To Me is still recognised. The next sync corrects an existing archive.
- **One meeting per recording.** A recording Teams re-posts later, or whose transcript notice lands near a different occurrence, now stays with the occurrence it belongs to.

## Security

- **Built with Go 1.27.2**, which fixes standard-library vulnerabilities in `net/http`, HTTP/2, `crypto/tls` and `net/textproto` (GO-2026-6603, GO-2026-6605, GO-2026-6607, GO-2026-6608, GO-2026-6610 to GO-2026-6613, GO-2026-6617).

## Install

### macOS

```sh
brew install ourostack/tap/m365crawl
```

Or download `m365crawl_<version>_darwin_arm64.tar.gz` or `m365crawl_<version>_darwin_amd64.tar.gz` from the release assets.

Reading Teams and Outlook needs Full Disk Access for your terminal or agent host (see docs/full-disk-access.md); `m365crawl doctor` tells you whether it is missing. Fetching transcripts needs Microsoft Edge or Google Chrome.

### Windows

Download `m365crawl_<version>_windows_amd64.zip` or `m365crawl_<version>_windows_arm64.zip`, unzip it, and run `m365crawl.exe`. The Windows assets are intentionally unsigned, so Windows may ask before the first run.

On Windows, m365crawl reads Teams chats, the Teams calendar and meeting transcripts. Outlook mail is not read on Windows yet.
