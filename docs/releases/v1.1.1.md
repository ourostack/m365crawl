# m365crawl v1.1.1

**Restore macOS Outlook mail and calendar reads after the October update.**

- Read event layout `0x6b/0x459` and mail-body layout `0xca/0x752`
  alongside the older supported layouts.
- Preserve established calendar identity and automatic links when an account
  layout is unknown, rather than treating it as confirmed empty identity.
- Keep a failed mail read visible as a stale-data notice in mail commands and
  mail-participating search, including offline reads, zero hits and selected
  fields. A successful mail read clears the failure.
- Preserve offline search compatibility with older readable archives that do
  not yet have retained failure storage.

Unknown layouts remain explicit. The observed account layout `0x49/0x1a12`
and attachment layout `0x16a/0x31e` are not newly supported. Attachment losses
remain partial coverage; neither the local cache nor this release promises
complete server history. Existing archive schema 19, public IDs, read-only
source handling and Windows mailbox-attribution guards remain unchanged.

## Install

On macOS, use `brew install ourostack/tap/m365crawl` or
`brew upgrade m365crawl`, or verify the matching Darwin tarball against
`checksums.txt`. Darwin binaries are Developer ID signed and notarized by the
normal release pipeline.

On Windows, download `m365crawl_1.1.1_windows_amd64.zip` or
`m365crawl_1.1.1_windows_arm64.zip`, verify it against `checksums.txt`,
unzip into a user-owned directory and run `m365crawl.exe`.
**Windows binaries are intentionally unsigned.**
