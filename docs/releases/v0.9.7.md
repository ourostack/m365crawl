# m365crawl v0.9.7

**Find the files OneDrive remembers, including its cached sharing records, in the same document archive as Office.**

## OneDrive usage and sharing

OneDrive keeps a local usage file with recently used files, formatted document variants and frequent collaborators. `docs sync` now archives those records. It does not open the documents or follow sharing links.

```sh
m365crawl docs sync
m365crawl docs list --application onedrive
m365crawl docs show document-observation:123
m365crawl docs sync --onedrive-usage-file /path/to/copy.db
```

Each row carries `variant` `onedrive_usage` and the native record in `usage_native`. Recent rows and document variants with the same native ID remain separate; `docs show` reports their same-capture relations. Sharing previews include counts and truncation flags. The `full_inspection` command reads the complete captured record from the archive.

Default discovery covers Mac Business account folders. Mac and Windows can read one ordinary local copy with `--onedrive-usage-file`. Personal account discovery, default Windows/Linux discovery and OneDrive library/sync databases are not included. Databases in write-ahead mode, or with WAL/SHM companions, remain refused.

## Reads no longer copy unchanged usage files

An ordinary read checks the source signature and skips an unchanged registry or usage file, even after the freshness window. Its `attempted_at` remains the last capture time. Explicit `docs sync` still captures the source. Unchanged captures share earlier membership instead of copying thousands of membership and relation rows.

## Let the archive explain its clocks

Recent-row clocks without a zone keep their exact raw text and have null parsed values. Date windows never guess a zone or substitute an access, sharing or capture time for modification time. List and search output reports how many otherwise-matching rows a date window excluded because they lack modification times.

```sh
m365crawl docs list --application registry --order-by opened_at --limit 5
m365crawl --max-age 0 docs search "launch plan" --application onedrive
```

Text lists show a separate usage-type column. Registry rows can be ordered by their stated opened time. Loop text lists now explain that they contain partial cached snapshots; compact application summaries include a loss total; search explains when a matched count is only a lower bound.

## Breaking change and upgrade

A default `docs sync` can now succeed when OneDrive usage is the only usable document family. `--root`, `--registry-file`, `--onedrive-usage-file` and `--source-id` are mutually exclusive.

The archive moves to schema 15 through an additive migration. Back up the archive before a writable command. Any sync, or read that refreshes first, can upgrade it; `--max-age 0` reads and `docs sources` leave schema 14 unchanged. After upgrade, an older binary refuses the archive with `archive_newer`. Run `m365crawl docs sync`, then `m365crawl doctor`.

See the [changelog](https://github.com/ourostack/m365crawl/blob/v0.9.7/CHANGELOG.md) and [SPEC](https://github.com/ourostack/m365crawl/blob/v0.9.7/SPEC.md) for the exact contract.

## Install and upgrade

On macOS, use `brew install ourostack/tap/m365crawl` or `brew upgrade m365crawl`. Alternatively, download the matching Darwin tarball and verify it against `checksums.txt`. Darwin binaries are Developer ID signed and notarized.

On Windows, download the matching amd64 or arm64 zip, verify its checksum, unzip it and replace `m365crawl.exe` in your user-owned installation. **Windows binaries are intentionally unsigned.**

## Usage-led, not exhaustive

Cached sharing names, addresses and thread IDs remain OneDrive's claims, not links to archived people or chats. Explicit SharePoint/Stream content and resident Office text are separate upcoming units. For another workflow, work with your agent to open a [prompt request](https://github.com/ourostack/m365crawl/issues/new?template=prompt-request.yml) using synthetic examples; never attach private caches, archives, document content or credentials.
