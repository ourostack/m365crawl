# m365crawl v1.0.1

**Safer incomplete reads, interrupted refreshes and shared snapshot lifetimes.**

This patch preserves the supported 1.x command and archive contract. The archive
remains schema 19; corrected decoder and mail-mapper stamps make existing
archives retry affected cached data through an ordinary sync.

## Retain evidence without inventing freshness

- Incomplete Teams observations keep readable records and calendar events
  without treating an incomplete key census as proof of removal or advancing
  calendar verification. A first incomplete calendar read still exposes retained
  events and exact-address Outlook links while replay remains pending.
- Unresolved report-significant omissions trigger another read even when the
  cache fingerprint is unchanged. Archive-only calendar recovery preserves
  existing source clocks and does not grant new verified coverage.
- Cancellation after a committed Outlook calendar keeps that result, reports
  interruption and leaves unread mail eligible for the next ordinary sync.

## Protect snapshots and recovery context

- Snapshot roots record protected ownership before copying. Stale cleanup needs
  positive owner-death evidence and a matching root identity; live, reused-PID,
  uncertain and legacy roots remain available to their readers.
- Recovery commands retain the selected archive, output format and applicable
  source/account context without carrying incompatible item flags.
- The measured extended Outlook for Mac folder layout restores folder names,
  kinds and message links. Unknown layouts still produce explicit partial-read
  diagnostics.
- The portable OWA acceptance oracle now decodes SQL's hexadecimal BLOB output
  before its bounded gzip/body comparison. This changes no production collector
  or storage contract.

Source coverage is still local-cache coverage, not complete service history.
Native source availability is unchanged; Windows OWA calendar ingestion is not
included.

## Install

On macOS, use `brew install ourostack/tap/m365crawl` or
`brew upgrade m365crawl`, or verify the matching Darwin tarball against
`checksums.txt`. Darwin binaries are Developer ID signed and notarized by the
normal release pipeline.

On Windows, download `m365crawl_1.0.1_windows_amd64.zip` or
`m365crawl_1.0.1_windows_arm64.zip`, verify it against `checksums.txt`,
unzip the Windows ZIP into a user-owned directory and run `m365crawl.exe`.
**Windows binaries are intentionally unsigned.**
