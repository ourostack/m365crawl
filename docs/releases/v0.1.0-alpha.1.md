m365crawl mirrors the Microsoft Teams desktop app's local cache into a SQLite archive on your Mac, with full-text search, unread state, mentions and the activity feed, so an AI agent can read your Teams history in milliseconds, offline and read-only. It reads only the signed-in desktop app's cache. It never talks to the Teams service and never writes to Teams' storage. This is an alpha: the JSON contract is meant to hold, but expect rough edges.

## Install

```sh
brew install ourostack/tap/m365crawl
```

The binary is unsigned, so macOS may block the first run. Allow it in System Settings > Privacy & Security, or remove the quarantine flag with `xattr -d com.apple.quarantine "$(which m365crawl)"`. Run `m365crawl doctor` first; it tells you if the terminal or agent host needs Full Disk Access.

## Highlights

- Commands: `doctor`, `whoami`, `sync`, `status`, `search`, `messages`, `thread`, `unread`, `activity`, `conversations`, `people` and a read-only `sql`.
- Agent-first JSON contract: one document per command on stdout, stable snake_case keys, lists as `{items, count, truncated}`, and errors as `{error: {code, message, fix}}` on stderr where `fix` is an instruction to follow.
- Freshness: every read result carries `archive_age_seconds`, and `--max-age 15m` syncs first when the archive is older.
- Context budget flags: `--limit`, `--fields` and `--max-text` keep results small.
- Deep links: every item has a Teams `link` for citing, and `thread` accepts one.
- Activity feed: mentions, replies and reactions joined with their messages.
- Unread and mentions semantics: `unread` covers chats and meetings by default (`--include-channels` adds channels, and results say `channels_excluded` when they are left out), `--by-conversation` gives the overview, and `mentions_me` is exact.

## Known issues

- Peak memory is about 1 GB during a full sync, because the LevelDB reader loads the whole origin. A fix is planned.
- Items from bots, call events and some activity types can have an empty sender or empty text.
- Some bot posts repeat, or show raw card JSON as their text.
- Thread roots do not show a reply count yet.
- There is no `--team` filter; use `conversations --query` to find a team's channels.
- `watch` is not available yet.
- The binary is unsigned.
