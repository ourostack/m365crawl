# m365crawl v0.3.1

`v0.3.1` hardens the Teams cache decoders and clarifies the agent skill. No archive change: a v0.3.0 archive is used as it is.

## Fixes

- A cached value whose Snappy header declares an impossible size (more than 32 times its compressed length) is now skipped with the omission `snappy_too_large` instead of being allocated in full. A tiny malformed record could otherwise ask for gigabytes of memory.
- A V8 array that carries named properties and is referenced more than once now keeps those properties at every reference. Before, the second and later references decoded as a plain list.
- Releases: Apple notarization waits at most 20 minutes per binary (`NOTARY_TIMEOUT`) and then fails with the reason, instead of running the release job into its timeout without one.

## Skill and docs

- `--to` is exclusive, and a signed offset such as `--from=-14d` counts from now, not from local midnight.
- An event's `recordings` (and `recording_count`) list recordings, transcripts and call events, told apart by `kind`; `matched_by: recap` is firm and `window` is likely.
- `mine_basis` appears with `mine: true` and on ambiguous items (`mine_basis: ambiguous`); `mine_ambiguous_omitted` is omitted when zero.

## Install

### macOS

```sh
brew upgrade ourostack/tap/m365crawl
```

Or download `m365crawl_<version>_darwin_arm64.tar.gz` or `m365crawl_<version>_darwin_amd64.tar.gz` from the release assets.

### Windows

Download `m365crawl_<version>_windows_amd64.zip` or `m365crawl_<version>_windows_arm64.zip`, unzip it, and run `m365crawl.exe`.

## Acceptance and verification

- `make acceptance-calendar` passed all 19 checks on real copies (counts, timings, paths and field names only).
- A full sync of the same real Teams cache with v0.3.0 and with this release gives identical counts (messages, records, calendar events and omissions), so the decoder fixes change nothing on real data.
- The release workflow verifies the downloaded darwin binaries and the Homebrew install, and the Windows zip files against `checksums.txt`.

## Signing note

The macOS release binaries are Developer ID signed and notarized. The Windows amd64 and arm64 zip assets are intentionally unsigned.
