# m365crawl v1.0.2

**Verified release notes and safer shutdown/mail cleanup.**

A compatible patch on the supported stable 1.x line. Commands, acquisition
defaults, archive schema 19 and native source availability are unchanged.

## Stable release delivery

- Require Go 1.27.3 or newer so builds include its `crypto/x509` security fixes.
- Preserve the supplied versioned release notes and signing disclosures. Missing
  or blank notes are refused before tag creation; a mismatched published body
  blocks flag restoration and Homebrew publication.
- Identify the supported stable 1.x contract explicitly in the release badge,
  installation instructions and embedded agent guide.

## Shutdown and reader lifetimes

- Wait for the owned file-event pump and its watcher-close call before watch
  shutdown returns.
- Retain a Windows Outlook mail snapshot when an aborted open or failed or
  panicking reader close cannot prove release. Preserve the primary failure or
  cancellation and report the retained snapshot without exposing cached content.
  Healthy reads and proved-canceled reads still remove their snapshot; a canceled
  watch keeps its normal successful-stop behavior.

Source coverage remains local-cache coverage, not complete service history.
Windows OWA calendar and several populated content mailboxes per profile are not
included.

## Install

On macOS, use `brew install ourostack/tap/m365crawl` or
`brew upgrade m365crawl`, or verify the matching Darwin tarball against
`checksums.txt`. Darwin binaries are Developer ID signed and notarized by the
normal release pipeline.

On Windows, download `m365crawl_1.0.2_windows_amd64.zip` or
`m365crawl_1.0.2_windows_arm64.zip`, verify it against `checksums.txt`,
unzip into a user-owned directory and run `m365crawl.exe`.
**Windows binaries are intentionally unsigned.**
