# m365crawl v0.4.0-rc.3 (rehearsal, deliberately failed, then resumed)

This is a rehearsal of the state-based release pipeline, not a release for users. It repeats the deliberate failure from docs/releasing.md to prove the resume fix for issue 78: the tap's deploy key is removed before this merges, so `publish-homebrew` must fail, `contain` must keep the release a prerelease and not latest, and the issue "Workflow failed: Release" must open. The key is then restored and the workflow dispatched again from main, and `decide` must resume this release at the publish stage without rebuilding it.

It is published as a GitHub prerelease, its cask goes only to the tap's `rehearsal` branch, and `brew install ourostack/tap/m365crawl` keeps serving the latest stable release. Do not install it for real use.
