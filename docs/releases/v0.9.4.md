# m365crawl v0.9.4

**Your agent can now tell which app or bot posted a Teams message, what it was replying to and what it cited.** Teams already keeps those claims in each message's native JSON. m365crawl reads them with strict, bounded parsing and puts them on every message result, so an agent summarizing a chat no longer mistakes a Copilot or workflow post for a person, or loses the sources behind an answer.

## Application evidence on every message

```sh
m365crawl sync
m365crawl messages --since 1d --limit 20 --fields id,sender_name,app_observation
m365crawl thread <conversation> <root-message-id>
m365crawl search "release date" --limit 5
```

- Each Teams message carries `app_observation` with a state: `mapped`, `partial`, `absent`, `failed` or `not_derived`. A mapped message names the app, the native reply-to message and up to 100 citations. If a message holds more, `full_inspection` gives the archive-only command that shows them all.
- Each result carries `application_evidence_coverage`, which counts the states of the Teams messages it returned, after `--limit`.
- `messages`, `unread`, `thread`, chat hits of `search` and the recent messages of `calendar event` share this shape. One message is still one item and one search hit.
- The claims are the message's own. They are not a verified app identity or a checked citation target.

## Upgrading

The archive moves to schema 12. The first writable `sync` after upgrading derives evidence for every archived message offline, before any capture, and reports `application_backfill`. On a large archive this takes seconds, and it needs up to about 0.75 GB of temporary free disk space for the write-ahead log, which is returned when it finishes. Until that sync runs, reads with `--max-age 0` report `not_derived`.

Run `m365crawl doctor` after upgrading.

## Changed

- `sql` prints BLOB columns, such as `records.raw_digest` and the new `messages.raw_digest`, as lowercase hex in every output format. Before, they came out as raw bytes that JSON could not preserve.

## Install and upgrade

On macOS, use `brew install ourostack/tap/m365crawl` or `brew upgrade m365crawl`. Alternatively, download the matching Darwin tarball and verify it against `checksums.txt`. Darwin binaries are Developer ID signed and notarized.

On Windows, download the matching amd64 or arm64 zip, verify its checksum, unzip it and replace `m365crawl.exe` in your user-owned installation. **Windows binaries are intentionally unsigned.**
