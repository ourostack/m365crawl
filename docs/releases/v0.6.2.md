# m365crawl v0.6.2

`v0.6.2` fixes transcript fetching on Windows and makes m365crawl easier for agents to use. No archive change: a v0.6.x archive is used as it is.

## Fixed

- **Edge on Windows.** On Windows, Edge's first process can hand the launch to another process and exit before the browser is ready. `transcripts fetch` and `transcripts signin` now wait for the browser through that handoff instead of failing with `transcripts_browser_failed`. When the browser closes, every process it started is still ended. (#139)
- **Sign-in on OneDrive hosts.** `transcripts signin` now opens the site of a part, as `transcripts fetch` does since v0.6.1, so a sign-in on a OneDrive host stays on that host.

## Changed

- **`--fields` keys in help.** Every command that takes `--fields` lists the keys it accepts in `--help` (and `--help --json`), from the same table its validation uses. (#134)
- **Better suggestions for a wrong command name.** A likely synonym now points at the right command: `chats` at `conversations`, `email` at `mail`, `meetings` at `calendar`, `recording` at `transcripts`, and so on. It is still a usage error, and its `fix` names the command's help. (#135)
- **Calendar cache freshness.** `calendar agenda` and `calendar actions` give each Teams account's `teams_cache_fresh_at`, the time Teams last refreshed its cached calendar. When the requested range starts after that time, a notice says that an event created or changed since then, such as a new invitation, appears only after Teams refreshes its calendar (open the Calendar in Teams, then run `m365crawl sync`). (#136)

## Install

### macOS

```sh
brew install ourostack/tap/m365crawl
```

Or download `m365crawl_<version>_darwin_arm64.tar.gz` or `m365crawl_<version>_darwin_amd64.tar.gz` from the release assets.

Reading Teams and Outlook needs Full Disk Access for your terminal or agent host (see docs/full-disk-access.md); `m365crawl doctor` tells you whether it is missing. Fetching transcripts needs Microsoft Edge or Google Chrome.

### Windows

Download `m365crawl_<version>_windows_amd64.zip` or `m365crawl_<version>_windows_arm64.zip`, unzip it, and run `m365crawl.exe`. The Windows assets are intentionally unsigned, so Windows may ask before the first run.

On Windows, m365crawl reads Teams chats, the Teams calendar and meeting transcripts. Outlook mail is not read on Windows yet.
