# m365crawl v0.5.0

`v0.5.0` adds Outlook mail. One local archive now holds your Teams chats, your Outlook mail and your calendar, and one `search` looks through chats and mail together. `calendar event` gathers what you need before a meeting, and `m365crawl` on its own tells you what it holds and where to start.

## Added

- **Outlook mail.** `sync` reads the new Outlook for Mac's mail into the archive next to Teams and the calendar: messages, folders, senders and recipients, read and flag state, bodies, and each attachment's name, size and type (the files are not copied). Read it with `mail list` (filter by folder, sender, date, unread, flagged or with attachments), `mail show`, `mail thread`, `mail folders` and `mail unread`. Outlook keeps only recent mail on the Mac, so every mail list says when the archive last synced and how far back Outlook's copy reaches.
- **One search for chats and mail.** `search` looks through Teams chats and Outlook mail together, newest first, and labels each result with its `source`. `--source chats` or `--source mail` searches one of them, and `--folder` searches one mail folder.
- **Meeting prep.** `calendar event` lists the mail about a meeting (the invite first, then messages with the same subject exchanged with attendees around the meeting) and the latest messages in its Teams meeting chat. `people` also lists the people you exchange mail with.
- **It explains itself.** `m365crawl` with no command shows what the archive holds for chats, mail and the calendar, how fresh each is, and what to run next. `--help` opens with a short "Start here" list, an empty result says why it is empty, and a mistyped command suggests the right one. The agent guide (`m365crawl skill`) is much shorter and points at `--help`.

## Changed

- **A faster archive.** Syncing a mailbox that has not changed writes nothing and indexes nothing again; a message body is compressed and converted only when it first arrives.
- **Archive format 6.** The archive gains the mail tables. A v0.4.0 archive is upgraded the first time this version syncs it.

## Fixed

- **Lower memory.** Reading Outlook takes much less memory (on a large synthetic mailbox, peak memory fell from 250 MiB to 137 MiB).
- **No hung syncs.** A damaged record in the Teams cache can no longer make a sync hang.

## Upgrading from an earlier version

The binary is `m365crawl`, the archive is `~/.m365crawl/m365crawl.db` (`%LOCALAPPDATA%\m365crawl\m365crawl.db` on Windows), and every environment variable starts with `M365CRAWL_`. Nothing reads the earlier names, so uninstall the earlier binary and update any scripts or agent settings that set its environment variables. To keep your history, move your existing archive to ~/.m365crawl/m365crawl.db (or the Windows path above) before the first sync.

## Install

### macOS

```sh
brew install ourostack/tap/m365crawl
```

Or download `m365crawl_<version>_darwin_arm64.tar.gz` or `m365crawl_<version>_darwin_amd64.tar.gz` from the release assets.

Reading Teams and Outlook needs Full Disk Access for your terminal or agent host (see docs/full-disk-access.md); `m365crawl doctor` tells you whether it is missing.

### Windows

Download `m365crawl_<version>_windows_amd64.zip` or `m365crawl_<version>_windows_arm64.zip`, unzip it, and run `m365crawl.exe`. The Windows assets are intentionally unsigned, so Windows may ask before the first run.

On Windows, m365crawl reads Teams chats and the Teams calendar now. Outlook mail is not read on Windows yet and comes in a later release; until then the `mail` commands say so, and `search` returns chats with a note.
