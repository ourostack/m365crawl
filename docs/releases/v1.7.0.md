# m365crawl v1.7.0

**Mail reads again.**

A compatible minor release on the stable 1.x line. Outlook for Mac mail reads recover on stores written since 2026-11-12, and the CLI gains a machine-readable command catalogue and safer write previews.

## Added

- `m365crawl help --json` prints every command with who sees its effect (`private` or `others`), whether it only reads, and its exit codes.
- Every write takes `--why` (the same as `--reason`), and `--dry-run` previews a write without sending or changing anything.
- `m365crawl watch <chat> --timeout DURATION` waits for a new message in one chat and answers a `wait/1` document, with a `--cursor` to wait again.

## Fixed

- Outlook for Mac mail reads no longer fail with `outlook_mail_layout_unsupported` on stores that use the `0x431` message header and `0x762` body layouts. Every other unknown layout is still refused. For `0x431` messages the flag byte is not established, so `flag` reads `unknown`.
- `content fetch image` accepts inline PNGs in Teams standard/private channel root posts (select the team with `--team-id` or a link's `groupId`; native channel export is not qualified here), `content fetch stream` lists native transcript candidates, browser commands with an already-cancelled context are safe, a closed pipe ends cleanly, and `edit`, `delete` and `remove` name the command that does the real change.

## Coverage and upgrade

No archive schema change. The mail mapper version rises to 6, so the next sync re-reads the Outlook store. Archived rows and tombstones are kept. Server completeness is not claimed.

Real-cache acceptance and native Windows checks for the new mail layouts were not part of this release's qualification; the installed-consumer recovery is reported separately on the issue.

## Install

On macOS, use `brew install --cask ourostack/tap/m365crawl` or `brew upgrade --cask m365crawl`, or verify the matching Darwin tarball against `checksums.txt`. Darwin binaries are Developer ID signed and notarized by the normal release pipeline.

On Windows, download `m365crawl_1.7.0_windows_amd64.zip` or `m365crawl_1.7.0_windows_arm64.zip`, verify it against `checksums.txt`, unzip into a user-owned directory and run `m365crawl.exe`.
**Windows binaries are intentionally unsigned.**
