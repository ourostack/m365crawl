# m365crawl v0.4.0-rc.1 (rehearsal)

This is a rehearsal of the state-based release pipeline, not a release for users. It is published as a GitHub prerelease, its cask goes only to the tap's `rehearsal` branch, and `brew install ourostack/tap/m365crawl` keeps serving the latest stable release.

It is one of two rehearsal notes files merged together (`v0.3.0-rc.2` and `v0.4.0-rc.1`). The pipeline must release the lower version first, then start itself again through `continue-release` and release the higher one in its own run. Do not install it for real use.
