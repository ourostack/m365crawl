# m365crawl v1.6.0

**One picture is worth its own bytes.**

A compatible minor release on the stable 1.x line. Inspect a cached Teams message's image references offline, then explicitly export one selected PNG. Message text remains text; its media coverage now says so.

## Added

- `content images` inventories image references from one exact cached Teams message without calling the server or fetching bytes.
- `content fetch image --image-id ID --output FILE` exports one uniquely bound PNG through the optional WorkIQ source. It verifies the current account, chat, message and selected reference, validates the PNG bytes, rechecks the binding and closes the native reader before publication.
- Output is private and never overwrites an existing file. Ownership and ACL checks use the open macOS/Windows file handles; an uncertain privacy result refuses the export instead of changing permissions. Error receipts say what was published or retained.
- Typed Teams message output discloses its returned-message media scope even with field projection. Search, calendar context and watch events retain their own bounded scope. Text export does not include image bytes or inspect the references.

## Coverage and upgrade

No archive schema change or full resync is required. Image inventory is offline; explicit acquisition requires the optional WorkIQ source and a current binding to the selected message. Export does not change the archive.

One successful PNG export is not complete media capture. Other image formats, channels, OCR and automatic fetching remain outside this release. It does not establish historical immutability, complete server history or a complete transcript.

Successful native WorkIQ acquisition on Windows, several populated Windows Outlook content mailboxes and a live protected-document view-only refusal remain unverified. Windows artifact and filesystem checks are not native Microsoft 365 acquisition proof. No new source or access permission is granted.

## Install

On macOS, use `brew install --cask ourostack/tap/m365crawl` or `brew upgrade --cask m365crawl`, or verify the matching Darwin tarball against `checksums.txt`. Darwin binaries are Developer ID signed and notarized by the normal release pipeline.

On Windows, download `m365crawl_1.6.0_windows_amd64.zip` or `m365crawl_1.6.0_windows_arm64.zip`, verify it against `checksums.txt`, unzip into a user-owned directory and run `m365crawl.exe`.
**Windows binaries are intentionally unsigned.**
