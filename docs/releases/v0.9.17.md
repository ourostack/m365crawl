# m365crawl v0.9.17

**Inspect retained Teams compose observations, without changing them.**

`drafts list` and `drafts show` expose strictly qualified own-account cached
regular-compose body projections already retained in the selected archive.
These commands are archive-only: they never acquire, refresh, discover, send,
edit or discard. There is no new acquisition or sync behavior, and draft bodies
do not enter shared messages, search, thread, unread, activity or FTS.
The archive schema remains 19; this release adds no migration.

## Choose the archive and account explicitly

Replace `ARCHIVE`, `TENANT/USER`, `teams-draft:HASH` and `BODY_SHA256` below with
your selected archive, account and the full locator/body digest printed by list.
No example is a native Teams address or a current-editor identifier.

```text
m365crawl --db ARCHIVE --account TENANT/USER --max-age 0 drafts list
m365crawl --db ARCHIVE --account TENANT/USER --max-age 0 --max-text 0 drafts list --include-removed --limit 50
m365crawl --db ARCHIVE --account TENANT/USER --max-age 0 --max-text 0 drafts show teams-draft:HASH --body-revision BODY_SHA256
```

List defaults to 50 items and a 300-Unicode-code-point text preview; show defaults
to full text and unexecuted HTML. Explicit `--max-text 0` keeps full text.
`--fields` is list-only. To inspect retained archive-removed bytes, opt in with
`--include-removed` on list/show; removal does not mean sent or discarded.

Prefer an item's emitted `full_inspection`, in its declared
`full_inspection_shell`: POSIX on Mac/Linux, or PowerShell7.3+ (`pwsh`) with
scoped Standard native argument passing on Windows. The Windows command is
**not CMD/batch or Windows PowerShell5.1 syntax**. Follow-ups preserve literal
selected archive/account values, removal opt-in and the full body guard.

## Read the evidence boundaries

`draft_coverage` survives item fields, limits, clipping and zero results.
Incomplete searches do not establish absence, and missing/ambiguous/incomplete
target association can coexist with an independently complete body. The
`body_revision` guard covers retained wrapper bytes/removal/qualification only;
target metadata and conversation evidence are freshly read outside that guard
(`target_guarded=false`). It does not create immutable or monotonic history.
Missing selected archives keep a generic unknown code with archive-missing
context, without acquiring anything.

These are cached observations, **not proof of current server-unsent state,
editor visibility, current chat/UI routing, lifecycle or all-drafts
completeness**. Not-marked-removed bytes can be older after a source decode
failure. Native qualification remains one Mac Space/team-side body plus
removed historical Chat shapes; Windows binary availability and archive-reader
portability do not establish Windows native draft acquisition qualification.

Private Copilot history and assigned Planner/Microsoft To Do task ingestion
remain unqualified and not included. Cached bot claims and recap actions are
not substitutes for those independent deferred sources.

## Install and platform scope

On macOS, use `brew install ourostack/tap/m365crawl` or
`brew upgrade m365crawl`, or verify the matching Darwin tarball against
`checksums.txt`. Darwin release binaries are Developer ID signed and notarized.

On Windows, download the matching amd64 or arm64 ZIP, verify its checksum,
unzip it and run `m365crawl.exe` from your user-owned installation.
**Windows binaries are intentionally unsigned.**
