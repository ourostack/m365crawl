# m365crawl v1.5.2

**Transcript coverage gets a clearer map, not a crystal ball.**

A compatible patch on the stable 1.x line. Populated transcript output gains explicit coverage metadata; existing transcript text, fetching, grouping, projections and archive schema are preserved.

## Added

- `transcripts show` reports `coverage_scope: "discovered_parts"` so a complete fetch is not mistaken for complete server discovery or recording speech coverage.
- Each segment includes `notice_duration_seconds` from its archived recording notice. A positive duration is a number; an unavailable or nonpositive duration is `null`, not an invented estimate.
- Plain transcript output names the same limited coverage scope. `complete` still means every discovered part has fetched text.

## Fixed

- Synthetic WorkIQ fetch-failure and recheck tests reuse existing real archive fixtures where appropriate, reducing repeated SQLite acquisition while retaining every fault sample, real handles, native-lock checks and existing deadlines. Crawler acquisition and required release gates are unchanged.

## Coverage and upgrade

No special sync or archive migration is required for these diagnostics. Read an already archived call with `m365crawl --no-sync transcripts show CALL_ID` to inspect its discovered parts without an implicit sync.

A recording notice duration is metadata, not a measurement of how much speech the transcript contains. This release does not recover an undiscovered transcript tail, establish complete server history or acquire inline-image bytes. Unknown coverage remains unknown.

Successful native WorkIQ acquisition on Windows, several populated Windows Outlook content mailboxes and a live protected-document view-only refusal remain unverified. Windows artifact checks are not native Microsoft 365 acquisition proof. No new source or access permission is granted.

## Install

On macOS, use `brew install --cask ourostack/tap/m365crawl` or `brew upgrade --cask m365crawl`, or verify the matching Darwin tarball against `checksums.txt`. Darwin binaries are Developer ID signed and notarized by the normal release pipeline.

On Windows, download `m365crawl_1.5.2_windows_amd64.zip` or `m365crawl_1.5.2_windows_arm64.zip`, verify it against `checksums.txt`, unzip into a user-owned directory and run `m365crawl.exe`.
**Windows binaries are intentionally unsigned.**
