# m365crawl v1.2.0

**Say when an archive answer is missing a source that stopped being read.**

- Add `source_health` and matching notices to participating Teams, mail,
  calendar, search and SQL reads, including offline reads and zero matches.
  Health stays outside item projection with `--fields`.
- Keep failures scoped to the sources and accounts each command actually reads.
  Show the last successful read and newest known archive modification when
  recorded; never invent an account or a historical timestamp.
- Add `failed_source_health` to sync reports without changing existing sync
  statuses. Keep interval-skipped failures visible and clear a failure only
  with a qualified successful read.
- Preserve legacy archive outcomes on read-only opens. Keep outcome-persistence
  errors visible, including through implicit refresh and cancellation, rather
  than claiming checked-empty health.
- Track future mail, folder and attachment modifications independently of
  published mail-state timestamps.
- Fix Homebrew verification ordering without weakening trust or signature
  checks.

Writable opens migrate the archive from schema 19 to schema 20. Older binaries
refuse newer archives; this is not a downgrade promise. Read-only legacy opens
do not migrate. Historical body or attachment write times that older versions
never recorded cannot be reconstructed.

This remains a local-cache reader, not complete server history. It adds no
WorkIQ source, protected Office-document extraction or support for several
Windows content mailboxes per profile. Existing source-admission and unknown
layout refusals remain intact.

## Install

On macOS, use `brew install --cask ourostack/tap/m365crawl` or
`brew upgrade --cask m365crawl`, or verify the matching Darwin tarball against
`checksums.txt`. Darwin binaries are Developer ID signed and notarized by the
normal release pipeline.

On Windows, download `m365crawl_1.2.0_windows_amd64.zip` or
`m365crawl_1.2.0_windows_arm64.zip`, verify it against `checksums.txt`,
unzip into a user-owned directory and run `m365crawl.exe`.
**Windows binaries are intentionally unsigned.**
