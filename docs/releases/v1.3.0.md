# m365crawl v1.3.0

**Read one Engage thread from the link someone shared.**

- Add `content fetch engage-thread URL` for an Engage thread URL or a supported
  Teams Engage deep link. Capture the observed starter and replies, native
  authors and clocks, safe links and generic attachment metadata.
- Keep immutable archived observations readable through `content show`,
  `content search`, shared `search --source content` and text output without
  reacquisition.
- Report partial coverage and losses explicitly. Unsafe signed or
  credential-bearing values are omitted or redacted. Attachments are not
  downloaded or classified into file/image types, and links grant no
  extraction rights.
- Wait for the requested browser document instead of accepting an already
  completed previous document. Selected-thread capture can separately qualify
  a fresh exact-target landing after a committed same-frame replacement, while
  retaining final native account, target and generation checks.

The archive remains schema 20. Existing Home observations and source-health
behavior remain intact; this is not a promise that older binaries can read
the new selected-thread representations.

Native selected-thread acquisition is qualified on macOS with the tool-owned
browser. Native Windows service acquisition, interactive sign-in challenges,
every future native variant and all-server reply completeness are not claimed.
This adds no WorkIQ source or protected Office-document extraction.

## Install

On macOS, use `brew install --cask ourostack/tap/m365crawl` or
`brew upgrade --cask m365crawl`, or verify the matching Darwin tarball against
`checksums.txt`. Darwin binaries are Developer ID signed and notarized by the
normal release pipeline.

On Windows, download `m365crawl_1.3.0_windows_amd64.zip` or
`m365crawl_1.3.0_windows_arm64.zip`, verify it against `checksums.txt`,
unzip into a user-owned directory and run `m365crawl.exe`.
**Windows binaries are intentionally unsigned.**
