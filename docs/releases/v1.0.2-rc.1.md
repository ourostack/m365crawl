# m365crawl v1.0.2-rc.1

**Publisher rehearsal for the stable 1.0.2 patch.** The supported product remains stable 1.x; this prerelease tests delivery and is not the default installation.

- Require Go 1.27.3, including its crypto/x509 security fixes.
- Preserve supplied release notes, refuse missing or blank notes before tag creation, and check the published body before flag restoration or Homebrew publication.
- Keep the README release badge on stable releases and describe the existing 1.x compatibility contract in the installation instructions and embedded guide.

Public commands, acquisition defaults and archive schema 19 are unchanged. Source coverage remains local-cache coverage, not server completeness. Windows OWA calendar and several populated content mailboxes per profile are not delivered by this patch.

This rehearsal exercises the normal signing, notarization, downloaded macOS/Windows artifact verification, published-notes check and rehearsal-tap path. The notes do not assert that those gates have already finished.

## Install

For ordinary macOS use, keep the latest stable Homebrew installation. This rehearsal must not update the stable m365crawl cask.

To inspect this candidate on Windows, download m365crawl_1.0.2-rc.1_windows_amd64.zip or m365crawl_1.0.2-rc.1_windows_arm64.zip, verify it against checksums.txt, unzip into a user-owned directory and run m365crawl.exe. **Windows binaries are intentionally unsigned.**
