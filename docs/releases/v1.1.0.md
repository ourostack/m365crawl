# m365crawl v1.1.0

**Windows Outlook calendar support.**

A compatible addition on the stable 1.x line. Existing commands, acquisition
defaults, public field meanings and archive schema 19 are preserved.

## Windows Outlook calendar

- Read cached calendar events from the new Outlook WebView2 OWA store alongside
  existing Windows mail support. Calendar queries, source counts and doctor use
  the supported public paths.
- Report calendar and mail read health independently. Retain an unlinked
  calendar profile when sign-in identity cannot be verified; never guess its
  account.
- Preserve explicit unknown attendee responses, available decoded Preview text,
  unresolved timezone labels and known UTC intervals. Retained uncertainty alone
  is not an omitted event. Malformed fields, unsupported values, partial
  attendees and unproved all-day dates still report loss.
- Keep last-good calendar evidence after later failures. OWA calendar deletion
  is not inferred, and HxStore-only block-health ratios are not applied to it.

The cache is not complete service history. Several populated content mailboxes
per Windows profile remain a separate, unsupported case with explicit attribution
guards; this release does not relax them. Sources remain read-only.

## Install

On macOS, use `brew install ourostack/tap/m365crawl` or
`brew upgrade m365crawl`, or verify the matching Darwin tarball against
`checksums.txt`. Darwin binaries are Developer ID signed and notarized by the
normal release pipeline.

On Windows, download `m365crawl_1.1.0_windows_amd64.zip` or
`m365crawl_1.1.0_windows_arm64.zip`, verify it against `checksums.txt`,
unzip into a user-owned directory and run `m365crawl.exe`.
**Windows binaries are intentionally unsigned.**
