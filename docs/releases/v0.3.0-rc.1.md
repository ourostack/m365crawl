# m365crawl v0.3.0-rc.1 (rehearsal)

This is a rehearsal of the state-based release pipeline, not a release for users. It is published as a GitHub prerelease, its cask goes only to the tap's `rehearsal` branch, and `brew install ourostack/tap/m365crawl` keeps serving v0.2.0.

It builds `main` as it stands, which includes skip-unchanged sync (schema 4) and the first calendar pieces; the calendar is not usable from the CLI yet. Do not install it for real use.

The rehearsal checks every job in order: `decide`, `verify`, `release` (signing and notarization), `verify-release-darwin`, `verify-release-windows` (amd64 and arm64), `settle`, `publish-homebrew` to the `rehearsal` branch, and `verify-homebrew`.
