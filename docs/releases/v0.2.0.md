# teamscrawl v0.2.0

`v0.2.0` adds Windows support without changing the read-only contract: the same Teams-cache mirror, the same stable JSON/error surface, Windows-native defaults, Windows CI/release verification, and local acceptance on a live Teams cache with counts-only evidence.

## Highlights

- Windows is now a supported host alongside macOS.
- Default Teams roots are `~/Library/Containers/com.microsoft.teams2/Data/Library/Application Support/Microsoft/MSTeams/EBWebView` on macOS and `%LOCALAPPDATA%\Packages\MSTeams_8wekyb3d8bbwe\LocalCache\Microsoft\MSTeams\EBWebView` on Windows.
- Default archive paths are `~/.teamscrawl/teamscrawl.db` on macOS and `%LOCALAPPDATA%\teamscrawl\teamscrawl.db` on Windows.
- Windows archive safety is private by construction: the default archive directory is created private before open, and a custom `--db` path fails with `db_error` before SQLite writes bytes when its direct parent or a pre-existing archive file is not already private.
- CI now proves the Windows-only files are exercised, and the release workflow verifies the downloaded Windows zip assets on native Windows runners.

## Install

### macOS

Install with Homebrew:

```sh
brew install ourostack/tap/teamscrawl
```

Or download `teamscrawl_<version>_darwin_arm64.tar.gz` or `teamscrawl_<version>_darwin_amd64.tar.gz` from the release assets.

### Windows

Download `teamscrawl_<version>_windows_amd64.zip` or `teamscrawl_<version>_windows_arm64.zip`, unzip it, and run `teamscrawl.exe`. Add the unzip directory to `PATH` if you want to launch it without the full path.

## Acceptance and verification

- macOS release verification still checks the downloaded darwin binaries plus Homebrew install for stable tags.
- Windows release verification checks the downloaded zip files against `checksums.txt`, confirms the PE architecture, proves the binaries are intentionally unsigned, and runs `teamscrawl.exe --json version` from the downloaded archive.
- Local real-cache acceptance for this release records only counts, timings, paths and field names; it never records message content, sender names, Teams ids, or token-shaped bytes.

## Signing note

The macOS release binaries are Developer ID signed and notarized when the release workflow has the Apple signing secrets. The Windows amd64 and arm64 zip assets are intentionally unsigned.
