# m365crawl v0.9.9

**Capture supported text from a resident Office file, then search and read it offline beside your archived Microsoft 365 content.**

## From a local file to searchable knowledge

```sh
m365crawl content capture --file "/absolute/path/project.docx"
m365crawl content capture --from document-observation:123
m365crawl content list
m365crawl content show local-text-observation:123
m365crawl search "launch plan" --source content
```

Choose one exact file or one archived document observation's original native local-file URL. An explicit `--kind docx|xlsx|pptx` supplies requested intent for a renamed file, not permission to skip package verification.

Capture positively qualifies an ordinary, already-resident file under the native no-materialization/no-recall and held-ancestry guards. It never opens Office, hydrates a placeholder, decrypts a protected document, crawls a directory or guesses a path from a cached title.

Ordinary content reads use only the archive, even when `--max-age` expires. They do not reopen the source file or fetch the network.

## Know which bytes and which text

Whole-file byte evidence, structured text representation and native file incarnation are separate. Repeated identical qualified captures keep their original observation IDs and clocks. Unknown native continuity remains unknown rather than merging equal text into one file identity.

Requested format is distinct from verified OOXML. Compound unreadable retains null verified format and no body; readable empty and partial supported projections remain separate states. Spreadsheet values are raw cached values, not recalculated formulas. Supported paragraphs and cells are not complete rendered Office layout.

A retained observation keeps its own immutable snapshot, counted losses and clocks. CURRENT and `snapshot_match` mean the last archived acquisition for that source instance, not a live source check or the newest incarnation at a reused path. An older incarnation can be retained while matching its own archived snapshot.

Previews show the first 100 native occurrences with full counts and clipping flags. The emitted `full_text_sql` returns the complete stored native result from the same archive. Sources and zero-hit searches keep independent coverage and validate the retained evidence/index bindings before presenting results.

## Upgrade

The archive moves to schema 17. Back it up before a writable command. Older archive-only reads report optional absence without migrating; an older binary refuses an archive after upgrade. Existing cloud, document, note, people, Loop and message IDs remain stable, and equal-time legacy/cloud search ordering is preserved.

The parser's existing finite source/member/text/occurrence limits are unchanged. Oversized input is an explicit failure, never a clipped successful document. The additional 32 MiB serialized-result guard is above the independently derived maximum output of the unchanged bounded producer.

## Install and qualification

On macOS, use `brew install ourostack/tap/m365crawl` or `brew upgrade m365crawl`, or verify the matching Darwin tarball against `checksums.txt`. Darwin binaries are Developer ID signed and notarized.

On Windows, download the matching amd64 or arm64 zip, verify its checksum, unzip it and replace `m365crawl.exe` in your user-owned installation. **Windows binaries are intentionally unsigned.**

Representative real Mac DOCX/XLSX/PPTX captures, explicit compound/size outcomes, immutable repeats, original-reference evidence and offline full-record parity were verified. Native Windows ordinary-file fixtures and portable archive contracts passed native CI; this does not qualify live Windows service acquisition, default file discovery or other filesystems. Linux can read retained archives, but local-file acquisition is not supported.

Disposable synthetic browser fixtures explicitly select mock-keychain automation and verify actual live flags and closure. Authenticated/product browser defaults remain unchanged.

## Scope

This release does not download original cloud Office documents, resolve sharing tickets, recalculate workbooks, perform OCR or infer file authors, account ownership or global document identity. Engage archive capture, Planner/To Do assignments and private Copilot history are not supplied by this slice. For another workflow, submit a [prompt request](https://github.com/ourostack/m365crawl/issues/new?template=prompt-request.yml) with synthetic examples, never private archives, content or credentials.
