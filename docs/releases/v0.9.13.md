# m365crawl v0.9.13

**Keep the truncation marker inside each `--max-text N` field's Unicode code-point budget.**

## Inclusive text bounds

Clipped display fields now retain the first N-1 Unicode code points followed by
the ellipsis, rather than retaining N code points and adding one more. At N=1,
a clipped field is the ellipsis alone. Exact-N, shorter and empty strings remain
unchanged; `--max-text 0` still disables the bound.

The limit is per applicable displayed text or preview field, not one aggregate
budget for an entire item. It counts Unicode code points, not UTF-8 bytes,
grapheme clusters or terminal columns. Combining sequences and emoji sequences
may be split at the boundary.

The shared correction applies to supported command surfaces, including Engage
content detail and previews. Help and reference text now describe the marker,
counting unit and supported scope instead of calling the flag list-only.

A clipped field intentionally carries one fewer original code point than the
previous off-by-one result. Clipping an already bounded string again at the
same N makes no new cut; existing aggregate truncation flags retain their
established meaning.

## Full evidence remains unchanged

Display shaping does not change archived text, native identifiers, digests,
clocks, loss metadata, block order, duplicates or empty occurrences. The
independent 100-block preview bound remains separate from the per-field text
bound. Use the emitted selected-archive, offline SQL command for the complete
original record.

There is no schema or mapper change from 0.9.12, no new acquisition or identity
resolution, and no change to sync freshness or archive-permission policy.
Generic SQL with default freshness is not the same workflow as the emitted
offline recovery command.

## Install and platform scope

On macOS, use `brew install ourostack/tap/m365crawl` or
`brew upgrade m365crawl`, or verify the matching Darwin tarball against
`checksums.txt`. Darwin binaries are Developer ID signed and notarized.

On Windows, download the matching amd64 or arm64 ZIP, verify its checksum,
unzip it and run `m365crawl.exe` from your user-owned installation.
**Windows binaries are intentionally unsigned.**

Synthetic POSIX read-only regression checks do not establish a Windows ACL
guarantee. This portable display correction adds no live Windows/Linux service
acquisition qualification.
