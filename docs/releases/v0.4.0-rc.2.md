# m365crawl v0.4.0-rc.2 (rehearsal, deliberately failed)

This is a rehearsal of the state-based release pipeline, not a release for users. It is the deliberate failure from docs/releasing.md: the tap's deploy key was removed before this merged, so `publish-homebrew` must fail, `contain` must keep the release a prerelease and not latest, and the issue "Workflow failed: Release" must open. The key is then restored and the workflow run again, which must resume and finish this release.

It is published as a GitHub prerelease, its cask goes only to the tap's `rehearsal` branch, and `brew install ourostack/tap/m365crawl` keeps serving the latest stable release. Do not install it for real use.
