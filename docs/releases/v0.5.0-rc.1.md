# m365crawl v0.5.0-rc.1 (rehearsal)

This is a rehearsal of the state-based release pipeline, not a release for users. It is the first release built, signed and published as m365crawl: the darwin archives, the Windows zips and the cask all carry the name `m365crawl`, and its cask is the first `Casks/m365crawl.rb` on the tap.

It is published as a GitHub prerelease, its cask goes only to the tap's `rehearsal` branch, and `brew install ourostack/tap/m365crawl` does not serve it. Do not install it for real use.
