### Added

- Directed writes through WorkIQ, off by default (#250). The person turns writes on with `m365crawl writes on`, typed on their own terminal. While writes are on, agents the person directs can send a plain-text Teams chat message (`writes send-teams-message`) or save a new mail draft (`writes save-mail-draft`) under the directed actions contract, with no second confirmation: every write names the agent and a reason, a chat message names the acting account and the chat's exact recipients, and an optional intent key and expected version stop double and stale sends. A message counts as sent only after it is read back from the server; an outcome m365crawl cannot establish is `unknown`, exits 5 and is never resent. `writes target`, `writes verify`, `writes settle` and `writes status` support the flow. The archive (schema 26) records every write and its changes.
