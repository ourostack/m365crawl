### Added

- Opt-in Microsoft Scout session history: `scout sync` copies the session files Scout keeps in your local OneDrive folder into the archive (macOS; Linux with `--root`), and `scout list`, `scout search`, `scout show` and `scout sources` read them offline. Only files already on this computer are read: a cloud-only file is counted in `scout_coverage` and never downloaded. Each version of a session is kept as an immutable observation with its digest, sessions Scout later deletes stay in the archive (`file_state` gone), and secrets are stored as `[redacted]` under the Teams scrub rules plus Scout rules for tool output (Bearer, GitHub, `sk-`, Slack, AWS and npm tokens, private keys, connection-string and URL secrets, `*_TOKEN`/`*_SECRET`/`*_PASSWORD`/`*_API_KEY` assignments, Cookie headers, and values under JSON keys that name a secret). When those rules or the session reader change, the next `sync` or `scout sync` scrubs and maps every archived session again in place from the archive alone, including sessions no longer in OneDrive, and overwrites the replaced text; `sync` reports `scout_rescrubbed`. Windows acquisition is refused (`scout_platform_unqualified`) until it is verified. The archive schema is now 21; the new tables are additive.

### Changed

- The help, agent guide, scope page and SPEC now say why private Copilot chat history is not included: Microsoft's export of Copilot interactions supports only an organization-wide application permission that an administrator must approve, not a signed-in user's own access.
