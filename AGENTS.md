# teamscrawl agent instructions

## Development rules

- Run every Go command with `GOWORK=off`. The Makefile and CI already do this.
- Run `make check` before opening a PR. It runs tidy, format, vet, lint (golangci-lint, govulncheck, actionlint), unit tests with the race detector, and the e2e tests.
- Every change reaches `main` through a PR with green CI. Pin every GitHub Action by full commit SHA with a trailing `# vX.Y.Z` comment.
- Never commit real Teams data, in fixtures, tests, logs, PR text or commit messages. Fixtures are synthetic and generated by the fixture generator (regeneration command is added with the fixture generator in a later task; `testdata/` files are binary and never reformatted).
- Never write to Teams' storage. Only decode the `replychain-manager` and `conversation-manager` databases. Never read Teams tokens.
- Signal handling lives only in `cli.Main`. Lower layers take a `context.Context` and clean up when it is cancelled.
- Tests that rely on `chmod 000` must skip when `os.Geteuid() == 0`.
- Do not add AI attribution anywhere: no `Co-Authored-By` trailers, no "Generated with" lines, no AI credit in commits, PRs, code comments or docs.
- Use conventional commit messages (`feat:`, `fix:`, `ci:`, `chore:`).

## Test hooks

- `TEAMSCRAWL_TEST_PAUSE_AFTER_SNAPSHOT=<duration>`: when set, the syncer sleeps that long after the snapshot is taken. Used only by the SIGINT e2e test.
